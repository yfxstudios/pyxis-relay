Wi-Fi hotspot

Saving restarts the hotspot. Everyone on it, including this page, disconnects for a few seconds and must rejoin the new network if you changed its name or password.

Camera & stream

Copy the file to a CFexpress card or USB-C drive. On the camera: Setup → page 11 → Import Stream Settings, choose PYXIS LAN Relay (RTMP), then turn Stream on.

Quality presets (bitrates in the profile)

Mbps, H.264. The camera picks the row that matches its streaming format. Download and import the profile again after changing these.

Camera's fixed address

Optional. Gives the camera the same address every time, so it's easy to find (e.g. for Blackmagic Camera Setup).

Start streaming automatically

The relay starts the camera's stream when the camera comes online, and again whenever it stops (even if it's stopped on the camera). If the camera says it's streaming but nothing reaches the relay for 30 seconds, it restarts it. To stop streaming for good, turn this off. Needs the camera's Web media manager on (Blackmagic Camera Setup → Network Access), and PYXIS LAN Relay (RTMP) selected as the camera's streaming platform; it never starts a stream to anywhere else.

The camera's Stream output gets the LUT loaded on the camera (for Film dynamic range, a normal Rec.709 picture instead of flat log, in every viewer). PYXIS Viewer's monitor LUTs go on top of that. Recorded clips aren't affected.

HDMI output

Shows the live stream on a screen plugged into the relay's HDMI port, using the chip's hardware decoder (up to 4K).

Smooth motion shows frames on the stream's own timeline, holding them briefly (typically 35–60 ms) so the camera's uneven delivery doesn't show as uneven motion. Lowest latency shows each frame at the screen's very next refresh, never below 48 Hz: about 70–80 ms sooner, but motion can be a little uneven.

Uses a refresh rate that's an exact multiple of the stream's frame rate, so every frame is shown for the same time: 48 Hz or more when the screen has one (25p → 50 Hz, 30p → 60 Hz). With Smooth motion it falls back to the stream's own rate (24p → 24 Hz, about 25 ms more delay, but no 24p-on-60 Hz stutter). Turn off to keep the screen's normal rate (usually 60 Hz). The screen may blank for a moment when it switches.

Admin & maintenance

Also used for SSH and for the advanced router settings.

Restarting the relay drops the camera's stream for a few seconds; the camera reconnects by itself. A reboot takes about a minute.
